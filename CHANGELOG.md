# Changelog

## Unreleased

- Added independent Sidebar and Identity with logo name layouts and a Capsule social layout.
- Added local logo upload, backup support and model compatibility checks.
- Added shared overlay themes, customizable backgrounds and live previews.
- Matched the presenter name background and width to the lower card by default.
- Added collapsible settings modules with General first and remembered open state.
- Expanded minified source and standardized formatting with Prettier and EditorConfig.
- Added browser regression checks for themes, persistence and legacy configurations.

## 1.0.0

- Initial public release.
- Animated name lower thirds and social-media overlay.
- Custom Browser Dock controller.
- English default UI with Brazilian Portuguese translation.
- Responsive dock layout.
- Configurable colors, font, width, position, and duration.
- JSON configuration import/export.
- Local OBS WebSocket integration with controlled reconnection behavior.
- Embedded YouTube, Facebook, and Instagram SVG icons.
- Fixed font selection so it applies to all visible overlay text.
- Added distinct system font choices and a presenter-name shadow toggle.

- Added an OBS-style custom scrollbar to the controller dock.
